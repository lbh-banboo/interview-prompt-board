# 开源前检查清单

发布或对外推送前逐项确认（不要把任何真实 Key 写进 issue、截图、演示视频或提交信息）。

1. **扫描密钥**

   ```bash
   .venv/bin/python tools/check_secrets.py
   ```

   - 扫描 `sk-[A-Za-z0-9]{16,}` 形态的 DeepSeek Key，以及当前进程环境变量
     `DASHSCOPE_API_KEY` / `DEEPSEEK_API_KEY` / `SEARCH_API_KEY` 和本机 `data/.env` 中的实际值。
   - 只输出文件名与行号，不输出 Key 值；命中时退出码为 1。
   - 测试夹具里的假 Key 可在该行标注 `# pragma: allowlist secret` 豁免；真实值命中不会被豁免。

2. **确认忽略规则**

   - `data/`（题库、录音、日志、`.env`）、`*.env`、`eval/` 下的个人录音/转写/截图、
     `output/`、`.venv/`、`node_modules/`、`*.sqlite3`、`.coverage` 等必须被 `.gitignore` 覆盖。
   - 初始化 git 后用 `git status --ignored` 检查是否仍有个人数据待提交。
   - `models/` 只保留 `MANIFEST.json`、许可证与小型配置；`.onnx` 权重不入库。
   - `third_party/` 只发布 `MANIFEST.json` 与各上游 LICENSE，源码快照由 `.gitignore` 排除（可用
     `tools/r0_fetch.py` 复现）；`research/` 与 `eval/retrieval/eval_set.json`（由个人主库派生）同样不发布。
   - 模型权重不入库：`.venv/bin/python tools/fetch_models.py` 按 MANIFEST 下载并校验，加 `--check` 只校验本地文件。

3. **轮换曾暴露过的 Key**

   - 只要 Key 曾出现在对话、日志、截图、录屏、评测报告或旧提交中，视为已泄漏：到对应控制台
     **吊销并重新生成**，不要只从文件中删除。
   - 重新生成后由使用者在本机填写：工作台“凭证”面板，或环境变量 / macOS 钥匙串。
   - 环境变量优先于界面保存值；要从界面配置生效，先取消对应环境变量并重启服务。

4. **确认首页视觉素材许可**

   - `web/landing/assets/` 下的背景视频、海报、logo 与两款点阵字体取自来源不明的参考页，
     见 `THIRD_PARTY_NOTICES.md`“首页视觉素材（来源待确认）”一节。
   - 开源发布前逐项确认或替换：不能确认许可的素材（视频、BubbledotICG 字体、logo）先换成
     自制 / CC0 / OFL 替代品，再移除对应 NOT VERIFIED 条目。
   - 2026-11-09 维护者决定按现状发布：NOT VERIFIED 条目保留在 `THIRD_PARTY_NOTICES.md`，收到权利人异议立即替换。

5. **最后验证**

   ```bash
   .venv/bin/python -m pytest -q
   npm test
   ```

   并确认工作台凭证面板保存后输入框清空、页面与网络响应里不出现明文 Key。
