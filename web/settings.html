    回答者资料

    重命名、删除已有资料，或编辑资料内容、关联答案库并同步更新。新建资料在会前配置向导里完成。正在进行中的会话使用资料时不能删除。

      开发者工具（故障注入说明） 

      from app.health.faults import FaultInjector
inj = FaultInjector()
inj.inject('asr', 'down')      # 可选：network / ws / asr / asr_stall / llm / search / voice / disk / source
inj.clear('asr')               # 恢复

      仅在测试中包装依赖；产品界面不提供注入接口，避免误触发现场故障。
