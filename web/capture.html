会话

会议音频怎么选
  • 网页会议：把会议放在 Chrome 标签页；“会议音频来源”选“共享浏览器标签页”，在共享选择器里选该标签页，并勾选“共享标签页音频”。
  • 桌面客户端（腾讯会议/飞书/Zoom）：浏览器抓不到客户端系统声音。可选方案是用虚拟声卡（如 BlackHole 2ch）把系统输出回环成输入设备，再选“使用虚拟声卡/第二输入设备”。
  • macOS 虚拟声卡配置：安装 BlackHole 2ch → 打开“音频 MIDI 设置” → 新建“多输出设备”（勾选耳机/扬声器 + BlackHole 2ch）→ 把系统输出设为该多输出设备 → 本页会议音频选 BlackHole 2ch。

虚拟声卡是可选方案，不是必须安装的软件。

会议音频无声音怎么办
  1. 网页会议：改选“Chrome 标签页”，并勾选“共享标签页音频”。
  2. 桌面客户端：用虚拟声卡，把系统输出设为“多输出设备”（耳机/扬声器 + BlackHole 2ch）。
  3. 确认对方正在说话，再看一次电平条。
